# Security policy

## Scope

This project helps reduce accidental PII exposure in local text files. It is **not** a certified de-identification or compliance product. See [docs/security.md](docs/security.md) for the full threat model.

## Reporting a vulnerability

- **Do not** open public GitHub issues with real PII, production exports, or map keys.
- Use [GitHub Security Advisories](https://github.com/alkitect/pii-intake-pseudonymizer-sn/security/advisories) (preferred) or contact the maintainer privately.
- Include: affected version, mode used (`--summary`, `--dry-run`, write), and a **redacted** reproduction if possible.

## Supported versions

Security fixes target the latest release tag on the default branch. Pre-release `main` may receive fixes at maintainer discretion.
